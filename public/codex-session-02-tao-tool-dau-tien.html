Tạo tool đầu tiên bằng ngôn ngữ tự nhiên.

Buổi này biến cảm giác “AI hay thật” thành “mình vừa làm được một tool”. Tool được chọn là Caption Mini Tool: có ô nhập, nút bấm, kết quả và nút copy. Người mới nhìn vào là hiểu ngay.

Copy prompt tạo tool Xem checklist test
Lumi Bot dẫn đường Đừng làm app lớn vội. Hôm nay chỉ cần một tool nhỏ chạy được.

Nhập thông tin, bấm một nút, có kết quả, copy được. Khi tool chạy rồi, mình mới nhờ Codex làm đẹp và sửa logic.

Sau buổi này, bạn làm được gì?

  • Mô tả một tool theo 3 phần: người dùng nhập gì, tool trả ra gì, giao diện cần gì.
  • Để Codex tự tạo project, code UI, chạy app và sửa lỗi.
  • Test app bằng mắt thay vì đọc code.
  • Yêu cầu Codex cải thiện giao diện, logic và trạng thái lỗi.

Trước khi bắt đầu cần chuẩn bị gì?

Buổi này chỉ cần project demo từ buổi 1 hoặc một folder mới. Đừng thêm AI API, database hay đăng nhập ở bước đầu.

1 Một folder để làm tool

Có thể dùng folder mới tên caption-mini-tool. Nếu chưa biết tạo, nhờ Codex tạo giúp.

2 Một ý tưởng thật nhỏ

Tool này chỉ làm một việc: nhập thông tin sản phẩm, tạo vài caption, copy để dùng.

3 Nguyên tắc: chạy được trước

Đẹp và thông minh để sau. Trước tiên cần app mở được, bấm được, ra kết quả được.

Vì sao chọn Caption Mini Tool?

Vì nó gần với công việc hằng ngày: bán hàng, marketing, shop online, freelancer, creator đều hiểu. Tool này đủ nhỏ để làm nhanh, nhưng đủ thật để bạn cảm thấy “à, mình có thể tạo công cụ riêng”.

Nguyên tắc buổi 2

Không cần backend. Không cần database. Không cần đăng nhập. Trước tiên chỉ cần một tool chạy được và dễ dùng.

Làm theo từng bước

1
Copy prompt tạo tool

Dán prompt chính vào Codex. Nếu Codex hỏi chọn công nghệ, hãy bảo chọn cách đơn giản nhất.

2
Để Codex tự tạo project và chạy thử

Bạn không cần đọc từng file. Chỉ cần quan sát Codex có chạy app, sửa lỗi và build không.

3
Mở app local và test bằng mắt

Nhập một sản phẩm đời thường, ví dụ: “cơm gà văn phòng”, “dịch vụ chụp ảnh”, “bánh biscotti healthy”.

4
Nếu kết quả chưa ổn, dùng prompt cải thiện UI/logic

Đừng tự sửa code. Hãy nói rõ: nút khó thấy, caption nhạt, mobile bị lệch, copy chưa có phản hồi.

5
Chạy build và commit

Khi app đã ổn, yêu cầu Codex build và commit. Đây là cách lưu lại phiên bản tool đầu tiên.

Kết quả đúng sẽ trông như thế nào?

✓ App có form nhập rõ ràng

Có ô tên sản phẩm, ô mô tả ngắn, lựa chọn tone, nút tạo caption và khu vực kết quả.

✓ Bấm một nút là có bản nháp

Kết quả chưa cần hoàn hảo. Chỉ cần đủ tốt để người dùng sửa nhẹ rồi đăng.

Nếu app không mở được

Dùng prompt sửa lỗi bên dưới. Yêu cầu Codex tự đọc terminal, browser console, sửa và chạy lại. Người mới không cần tự đọc log dài.

Prompt tạo Caption Mini ToolCopy dùng ngay
Tôi là người non-tech. Hãy tạo cho tôi một web tool đơn giản tên caption-mini-tool.

Tool cần có:
- Ô nhập tên sản phẩm
- Ô nhập mô tả ngắn
- Lựa chọn tone: vui vẻ, chuyên nghiệp, sang trọng
- Nút Generate
- Hiển thị 3 caption tiếng Việt
- Mỗi caption có nút Copy

Yêu cầu:
- Tự chọn stack đơn giản, ưu tiên Vite + React nếu phù hợp
- Giao diện sạch, dễ dùng, responsive
- Chưa cần AI API, hãy dùng logic/template local trước
- Chạy local để kiểm tra
- Nếu lỗi, tự sửa đến khi chạy được
- Chạy build
- Khởi tạo Git nếu chưa có
- Commit code với message rõ nghĩa
- Chưa push GitHub cho đến khi tôi báo

Trong quá trình làm, giải thích ngắn gọn bằng tiếng Việt.
Đây là prompt chính của buổi 2.

Checklist test bằng mắt

1
Nhập tên sản phẩm

Ví dụ: “Bánh biscotti healthy”. Caption có nhắc đúng tên sản phẩm không?

2
Nhập mô tả ngắn

Ví dụ: “ít ngọt, nhiều hạt, phù hợp dân văn phòng”. Caption có dùng đúng ý không?

3
Đổi tone

Khi đổi từ vui vẻ sang chuyên nghiệp, giọng caption có khác không?

4
Bấm Copy

Copy xong có phản hồi rõ không? Người dùng có biết đã copy thành công không?

Bài tập tự làm sau buổi 2

Đổi Caption Mini Tool thành một tool khác

Chọn một trong ba ý tưởng: tool viết email phản hồi khách hàng, tool tạo checklist onboarding nhân viên, hoặc tool lên lịch đăng bài 7 ngày. Giữ nguyên công thức: input, output, giao diện, nút copy.

Hãy cải thiện UI và logic của tool.

Yêu cầu UI:
- Giao diện gọn, hiện đại, dễ dùng
- Mobile đọc được
- Form rõ ràng
- Kết quả hiện thành từng khối riêng
- Nút Copy dễ thấy

Yêu cầu logic:
- Mỗi lần bấm Generate tạo 3 caption khác nhau
- Caption phải có tên sản phẩm
- Caption phải theo tone đã chọn
- Nếu thiếu tên sản phẩm, hiện thông báo yêu cầu nhập
- Nếu thiếu mô tả, vẫn tạo caption được nhưng ngắn hơn

Sau khi sửa:
- Chạy app để kiểm tra
- Chạy build
- Nếu build lỗi thì tự sửa đến khi pass
Dùng sau khi app đã chạy, để nâng từ demo thô thành tool dễ dùng.

Checklist cuối buổi

  • Tool chạy được local.
  • Generate ra kết quả nhìn được.
  • Có validation khi thiếu thông tin quan trọng.
  • Build pass hoặc bạn biết prompt để yêu cầu Codex fix build.
  • Có commit rõ nghĩa.
