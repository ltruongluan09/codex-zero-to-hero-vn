Hôm nay bạn tạo được: Caption Mini Tool.

Không backend, không database, không đăng nhập. Chỉ cần một web tool đơn giản, dễ hiểu, chạy được.

Lumi Bot dẫn đường Đừng làm app lớn. Làm một nút chạy được trước.

Sau khi tool chạy, mình mới nhờ Codex làm đẹp, sửa chữ, thêm copy, thêm trạng thái lỗi. Làm nhỏ nên bạn không bị ngợp.

Sau buổi này, bạn làm được gì?

  • Mô tả tool bằng 3 phần: người dùng nhập gì, tool trả ra gì, màn hình cần gì.
  • Nhờ Codex tự tạo app: bạn không cần tự viết từng dòng code.
  • Test như người dùng: nhập thử, bấm thử, xem kết quả có dùng được không.

Trước khi bắt đầu cần chuẩn bị gì?

1Một folder mới

Ví dụ: caption-mini-tool. Nếu chưa có, nhờ Codex tạo.

2Một ví dụ đời thường

Ví dụ: cơm gà văn phòng, lớp tiếng Anh, dịch vụ chụp ảnh.

3Chỉ một mục tiêu

Bấm tạo caption được. Đẹp và thông minh để sau.

Làm theo từng bước

1
Copy prompt tạo tool

Dán vào Codex và để Codex tự chọn cách đơn giản nhất.

2
Mở app local

Nếu Codex báo app chạy ở link local, mở link đó và nhìn như một user thật.

3
Test bằng mắt

Nhập sản phẩm, bấm tạo, thử copy. Chưa cần đọc code.

4
Nhờ Codex sửa tiếp

Nói bằng tiếng Việt: nút chưa rõ, chữ khó đọc, mobile lệch, caption chưa tự nhiên.

Prompt tạo Caption Mini ToolCopy dùng ngay
Tôi là người non-tech.
Hãy tạo cho tôi một web tool đơn giản tên caption-mini-tool.

Tool cần có:
- Ô nhập tên sản phẩm/dịch vụ
- Ô nhập mô tả ngắn
- Nút "Viết caption"
- Kết quả gồm 3 caption tiếng Việt
- Mỗi caption có nút Copy

Yêu cầu:
- Tự chọn cách làm đơn giản nhất
- Giao diện sạch, dễ dùng, mobile đọc được
- Chưa cần AI API, dùng template local trước
- Chạy local để kiểm tra
- Nếu lỗi, tự sửa đến khi chạy được
- Chạy build nếu có
- Commit code với message rõ nghĩa

Giải thích ngắn gọn bằng tiếng Việt khi xong.
Dán prompt này vào Codex. Đây là “một chạm” của buổi 2.

Bài tập tự làm

Đổi thành tool khác nhưng giữ công thức

Tool viết email, tool tạo checklist, hoặc tool lên lịch đăng bài. Vẫn là: nhập thông tin → bấm nút → có kết quả → copy.

Checklist cuối buổi

  • Tool mở được trên máy.
  • Nhập được thông tin.
  • Bấm nút có kết quả.
  • Copy được hoặc có phản hồi rõ.
  • Có commit lưu lại phiên bản đầu tiên.
