Sau khi tạo được tool đầu tiên, bước tiếp theo là làm cho Codex bớt “đoán mò”: biết bạn thích cách làm nào, điều gì không được làm, và cần kiểm tra gì trước khi kết thúc.

Hôm nay bạn tạo được: nội quy làm việc cho Codex.

Đây là cách biến Codex từ “AI làm theo từng câu” thành “cộng sự hiểu cách bạn muốn làm việc”.

Lumi Bot dẫn đường Đừng học thuật ngữ. Hãy hiểu như nội quy team.

AGENTS.md là nội quy trong project. Memory là thói quen nên nhớ. Skill là checklist dùng lại. Chỉ vậy thôi.

Sau buổi này, bạn làm được gì?

  • Tạo AGENTS.md: file nhắc Codex cách làm việc trong project.
  • Biết Memory nên lưu gì: thói quen làm việc, không phải mật khẩu hay API key.
  • Có checklist trước khi giao bài: xem file đã sửa, build/test, gợi ý commit.

Trước khi bắt đầu cần chuẩn bị gì?

Prompt tạo AGENTS.mdNội quy project
Hãy tạo file AGENTS.md cho project này.

Tôi là người non-tech, muốn Codex làm việc theo cách sau:
- Giải thích ngắn gọn bằng tiếng Việt
- Trước khi sửa code, đọc project để hiểu
- Ưu tiên cách làm đơn giản
- Không xóa file nếu chưa hỏi
- Không push GitHub nếu tôi chưa yêu cầu
- Nếu app lỗi, tự đọc log và sửa
- Sau khi sửa, chạy build/test nếu có
- Cuối task, báo file đã sửa và lệnh đã chạy

Hãy viết AGENTS.md ngắn gọn, dễ hiểu.
Sau đó commit thay đổi này.
Dùng để tạo “nội quy làm việc” cho Codex.
Prompt hỏi Memory nên lưuAn toàn
Hãy đề xuất Memory nên lưu cho tôi khi làm việc với Codex.

Bối cảnh:
- Tôi là người non-tech
- Tôi dùng Windows
- Tôi thích giải thích tiếng Việt, ngắn gọn
- Tôi muốn Codex tự xử lý code/build/Git nếu có thể
- Tôi chỉ muốn bị hỏi khi cần quyền, đăng nhập, API key, tạo repo mới hoặc push GitHub

Hãy trả về:
- Memory nên lưu
- Memory không nên lưu
- Nhắc tôi không lưu secret
Nhớ: Memory không phải nơi lưu mật khẩu.
Prompt tạo checklist ship-checkWorkflow dùng lại
Hãy tạo một checklist/workflow tên ship-check cho project này.

Mục đích:
- Dùng trước khi kết thúc task
- Kiểm tra Git status
- Xem file nào đã thay đổi
- Chạy build/test nếu có
- Báo lỗi nếu build/test fail
- Gợi ý commit message rõ nghĩa
- Không push GitHub nếu tôi chưa yêu cầu

Hãy viết hướng dẫn thật ngắn, dễ hiểu và commit thay đổi nếu có.
Dùng để Codex có nghi thức kiểm tra trước khi giao bài.
