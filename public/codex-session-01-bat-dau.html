Copy một câu. Để Codex tạo file đầu tiên.

Buổi này không dạy code. Bạn chỉ cần thấy Codex có thể kiểm tra project, tạo file thật và lưu lại một mốc thay đổi.

Copy prompt đầu tiên Xem 3 bước làm
🎯
Hôm nay bạn tạo được: README.md đầu tiên.

README giống tờ giới thiệu project. Có file này nghĩa là Codex đã thật sự làm việc trong folder của bạn.

Lumi Bot dẫn đường Nếu bạn chưa hiểu Git, terminal hay Node, không sao.

Việc đầu tiên không phải là học hết thuật ngữ. Việc đầu tiên là để Codex kiểm tra và nói bằng tiếng Việt: máy bạn đã sẵn sàng tới đâu.

Sau buổi này, bạn làm được gì?

  • Biết Codex khác ChatGPT ở đâu: ChatGPT giúp nghĩ, Codex giúp làm trong project.
  • Biết copy prompt để Codex kiểm tra môi trường: không phải tự đọc lỗi dài.
  • Có file README và một mốc lưu thay đổi: đây là viên gạch đầu tiên của project.

Trước khi bắt đầu cần chuẩn bị gì?

1Một folder trống

Ví dụ: codex-training-demo. Đừng dùng folder quá nhiều file lạ.

2Codex mở trong folder đó

Nếu không chắc, prompt bên dưới sẽ nhờ Codex kiểm tra giúp.

3Tâm lý thử trước

Chưa cần hiểu hết. Chỉ cần làm được bước đầu tiên.

Làm theo từng bước

1
Copy prompt kiểm tra môi trường

Dán vào Codex để biết máy đã có gì, thiếu gì.

2
Copy prompt tạo README

Đây là khoảnh khắc bạn thấy Codex tạo file thật.

3
Nhìn kết quả, chưa cần đọc code

Chỉ cần thấy file xuất hiện và Codex báo đã lưu mốc hoặc báo lý do chưa lưu được.

Prompt kiểm tra môi trườngBước 1
Tôi là người non-tech.
Hãy kiểm tra folder hiện tại đã sẵn sàng để học Codex chưa.

Kiểm tra giúp tôi:
- Đây có phải folder project không
- Git đã có chưa
- Node/npm đã có chưa
- Có thể tạo file thử không

Không sửa file ở bước này.
Hãy trả lời bằng tiếng Việt thật ngắn: cái gì đã sẵn sàng, cái gì chưa.
Dùng để Codex tự soi môi trường thay bạn.
Prompt tạo file đầu tiênBước 2
Hãy tạo file README.md cho project demo này.

Nội dung thật đơn giản:
- Tên project: Codex Training Demo
- Mục tiêu: học cách nhờ Codex tạo tool bằng AI
- Ghi chú: đây là file đầu tiên của project

Sau đó:
- Nếu project chưa có Git, hãy khởi tạo Git
- Commit README.md với message rõ nghĩa
- Không push lên GitHub

Giải thích ngắn gọn bằng tiếng Việt khi xong.
Đây là hành động tạo ra kết quả đầu tiên.

Kết quả đúng sẽ trông như thế nào?

✓Có file README.md

Mở folder thấy file mới. Nội dung đọc được bằng tiếng Việt hoặc tiếng Anh đơn giản.

✓Codex báo đã lưu mốc

Nếu chưa lưu được, Codex nói rõ thiếu gì. Như vậy vẫn là tiến bộ.

Prompt cứu hộKhi bị kẹt
Tôi bị kẹt ở buổi 1.
Hãy nói thật dễ hiểu:
- Tôi đang thiếu gì
- Có cần xử lý ngay không
- Tôi có thể học tiếp không
- Bước tiếp theo nên làm gì

Đừng giải thích quá kỹ thuật.
Dùng khi Codex báo lỗi bạn không hiểu.

Bài tập tự làm

Đổi README thành ý tưởng tool của riêng bạn

Ví dụ: tool viết email, tool tạo checklist, tool đọc tài liệu. Chỉ cần mô tả ý tưởng, chưa cần code.

Checklist cuối buổi

  • Bạn đã copy prompt vào Codex.
  • Codex đã kiểm tra môi trường hoặc nói rõ thiếu gì.
  • Project có README.md.
  • Bạn hiểu: mình không cần giỏi code để bắt đầu.
