Session 1 · 90 phút

Dùng Codex như một lập trình viên AI.

Buổi đầu tiên không cố dạy code. Mục tiêu là để bạn thấy Codex có thể đọc project, chạy lệnh, sửa file và lưu lại thay đổi. Khi thấy Codex làm được việc thật, phần kỹ thuật sẽ bớt đáng sợ hơn nhiều.

Làm bài thực hành Copy prompt buổi 1
Lumi Bot dẫn đường Bắt đầu nhẹ thôi: kiểm tra môi trường, tạo README, lưu mốc đầu tiên.

Nếu thấy Git, Node hay terminal hơi lạ, cứ để Codex kiểm tra giúp. Buổi này chỉ cần thấy Codex làm được việc thật.

Sau buổi này, bạn làm được gì?

  • Hiểu Codex khác ChatGPT ở điểm nào bằng ngôn ngữ rất đời thường.
  • Biết đưa một yêu cầu tiếng Việt để Codex tự kiểm tra môi trường.
  • Hiểu 6 từ tối thiểu: project, terminal, build, Git, commit, push.
  • Tạo được một file README và có một commit local đầu tiên.

Trước khi bắt đầu cần chuẩn bị gì?

Đừng để phần cài đặt làm người mới hoảng. Buổi này chỉ cần đủ để Codex mở được một folder và thử tạo file đầu tiên.

1 Một folder trống

Tạo folder tên dễ hiểu, ví dụ codex-training-demo. Đây là nơi Codex sẽ làm việc.

2 Codex đang mở trong folder đó

Nếu chưa chắc đang ở đúng folder, cứ nhờ Codex kiểm tra bằng prompt bên dưới.

3 Tâm lý: chưa cần hiểu hết

Git, Node, terminal nghe lạ cũng không sao. Hôm nay mình chỉ cần biết cái nào đã sẵn sàng.

Hãy hiểu buổi này như thế nào?

“Hôm nay mình không học lập trình theo kiểu ngồi học từng dòng code. Mình học cách giao việc cho Codex. Bạn sẽ nói rõ mình muốn gì, nhìn kết quả, rồi yêu cầu Codex sửa. Những phần như đọc lỗi, chạy lệnh, tạo file, commit code, mình để Codex làm.”

Câu nhớ nhanh

ChatGPT giống người tư vấn. Codex giống một dev AI đang ngồi trong project của bạn.

Làm theo từng bước

1
Mở Codex trong folder rỗng

Đặt tên folder rõ ràng, ví dụ: codex-training-demo. Đừng bắt đầu trong folder có quá nhiều file lạ.

2
Paste prompt kiểm tra môi trường

Copy prompt “kiểm tra môi trường” ở phần dưới, dán vào Codex, rồi chờ Codex báo cái gì đã có, cái gì còn thiếu.

3
Đọc kết quả bằng mắt thường

Nếu Codex báo thiếu GitHub CLI hoặc chưa đăng nhập GitHub, vẫn có thể học tiếp. Buổi này chưa cần push.

4
Paste prompt tạo README

README là cách nhẹ nhất để thấy Codex có thể tạo file thật trong project.

5
Xem commit đầu tiên

Commit là một lần lưu mốc thay đổi có ghi chú. Chưa cần học Git sâu, chỉ cần biết “mình đã lưu lại một phiên bản”.

Kết quả đúng sẽ trông như thế nào?

✓ Trong folder có file README.md

Mở ra thấy tên project, mục đích project và ghi chú cách chạy sẽ bổ sung sau.

✓ Codex báo đã commit hoặc báo lý do chưa commit

Nếu chưa commit được vì thiếu Git, đó vẫn là kết quả tốt: bạn đã biết máy còn thiếu gì.

Nếu bị kẹt ở bước này

Đừng tự mò lỗi. Copy prompt cứu hộ ở cuối bài và yêu cầu Codex nói bằng tiếng Việt: thiếu gì, có nghiêm trọng không, và có thể học tiếp không.

Đổi README thành một ý tưởng tool của riêng bạn

Ví dụ: tool tạo checklist công việc, tool viết email phản hồi khách hàng, tool tính giá dịch vụ. Chưa cần code, chỉ cần mô tả rõ ý tưởng trong README.

Checklist cuối buổi

  • Học viên biết đưa prompt vào Codex.
  • Học viên hiểu Codex đang làm gì ở mức đơn giản.
  • Project có README.
  • Có commit local hoặc hiểu vì sao chưa commit được.
