4 buổi để tự tạo tool đầu tiên bằng AI.

Không học lý thuyết dài. Bạn copy prompt, để Codex làm phần kỹ thuật, rồi tự kiểm tra kết quả bằng mắt. Mục tiêu cuối series: có một tool nhỏ chạy được và biết cách nhờ Codex sửa tiếp.

✨
Bạn không cần hiểu code trước. Bạn cần biết giao việc rõ.

Codex giống một cộng sự kỹ thuật AI. Bạn nói muốn tạo gì, Codex đọc project, sửa file, chạy thử và báo lại.

Lumi Bot dẫn đường Mình sẽ giữ cho bạn đi đúng đường: làm nhỏ, thấy kết quả, rồi nâng cấp.

Mỗi buổi chỉ có một việc chính. Nếu bị lỗi, bạn có prompt cứu hộ. Nếu thấy quá kỹ thuật, quay lại câu hỏi: “hôm nay mình cần tạo ra thứ gì?”

Bắt đầu trong 3 phút

1Mở Codex

Mở một folder trống hoặc project nhỏ. Không cần chuẩn bị hoàn hảo.

2Copy prompt

Mỗi buổi có prompt sẵn. Bạn chỉ cần dán và chờ Codex làm.

3Kiểm tra bằng mắt

App có mở không? Nút có bấm được không? Kết quả có dùng được không?

4 buổi, mỗi buổi làm ra một thứ thật

1 Thấy Codex tạo file đầu tiên

Copy một prompt để Codex kiểm tra môi trường, tạo README và lưu mốc đầu tiên.

Mở Session 1 → 2 Tạo tool viết caption đầu tiên

Một tool có ô nhập, nút bấm, kết quả và copy. Nhìn phát hiểu, bấm phát chạy.

Mở Session 2 → 3 Dạy Codex làm đúng “gu” của bạn

Tạo nội quy project, thói quen cần nhớ và checklist kiểm tra trước khi giao bài.

Mở Session 3 → 4 Đóng gói để người khác dùng thử

Viết README dễ hiểu, chạy build/test, commit và chuẩn bị chia sẻ an toàn.
