# Project: Dashboard

## Mục tiêu

Tạo dashboard để xem nhanh số liệu quan trọng trong công việc.

## Công cụ này giúp gì?

Dashboard giúp người quản lý không phải mở nhiều file Excel chỉ để trả lời các câu hỏi như: tháng này doanh thu bao nhiêu, team nào đạt KPI, chi phí tăng ở đâu.

## Người không biết code có làm được không?

Có, nếu bạn bắt đầu bằng dữ liệu mẫu. Sau đó mới tính chuyện nối dữ liệu thật.

## Gợi ý prompt

```text
Tạo dashboard quản lý doanh thu cho một công ty dịch vụ nhỏ. Cần có KPI card, biểu đồ doanh thu theo tháng, bảng top khách hàng, bộ lọc theo khu vực và trạng thái rỗng. Dùng dữ liệu mẫu trước.
```

## Kết quả mong muốn

- Màn hình KPI rõ ràng.
- Bảng dữ liệu dễ đọc.
- Biểu đồ đơn giản.
- UI phù hợp để trình bày trong cuộc họp.
