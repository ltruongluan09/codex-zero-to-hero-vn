# Project: Excel helper

## Mục tiêu

Tạo công cụ hỗ trợ xử lý dữ liệu dạng bảng như CSV hoặc Excel.

## Công cụ này giúp gì?

Nhiều công việc văn phòng lặp lại quanh Excel: lọc dữ liệu, gộp file, tổng hợp theo phòng ban, tìm dòng sai, xuất báo cáo. Excel helper giúp biến các thao tác lặp lại thành một nút bấm.

## Người không biết code có làm được không?

Có, miễn là bạn mô tả rõ file đầu vào có cột nào và kết quả đầu ra cần gì.

## Gợi ý prompt

```text
Tạo tool upload file CSV danh sách nhân viên. Tool cần hiển thị bảng dữ liệu, cho lọc theo phòng ban, đếm số nhân viên mỗi phòng ban và xuất kết quả tổng hợp. Dùng giao diện dễ hiểu cho HR.
```

## Kết quả mong muốn

- Upload dữ liệu mẫu.
- Xem bảng.
- Lọc và tổng hợp.
- Có nút xuất kết quả.
