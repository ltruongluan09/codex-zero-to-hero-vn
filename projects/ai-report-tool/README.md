# Project: AI report tool

## Mục tiêu

Tạo công cụ nhập gạch đầu dòng và sinh bản nháp báo cáo bằng AI.

## Công cụ này giúp gì?

Thay vì mất 30 phút viết báo cáo tuần, người dùng nhập các ý chính như việc đã làm, số liệu, khó khăn, kế hoạch tuần sau. Tool sẽ tạo bản nháp rõ ràng để chỉnh lại.

## Người không biết code có làm được không?

Có. Đây là project rất hợp với manager, PM, HR, marketing và backoffice.

## Gợi ý prompt

```text
Tạo tool sinh báo cáo tuần. Người dùng nhập việc đã làm, kết quả đạt được, khó khăn, kế hoạch tuần tới và ghi chú. App tạo bản nháp báo cáo tiếng Việt chuyên nghiệp, có thể copy ra email.
```

## Kết quả mong muốn

- Form nhập thông tin.
- Nút tạo báo cáo.
- Khu vực preview báo cáo.
- Nút copy nội dung.
