# Prompt debug và fix lỗi

```text
Tôi đang gặp lỗi trong project.

Tôi đã làm thao tác này:
[mô tả bạn đã bấm gì hoặc chạy lệnh gì]

Lỗi hiển thị:
[dán thông báo lỗi]

Mong muốn đúng là:
[mô tả kết quả bạn kỳ vọng]

Hãy:
1. Giải thích lỗi bằng ngôn ngữ dễ hiểu.
2. Tìm file liên quan.
3. Sửa lỗi.
4. Chạy lại để kiểm tra.
5. Nói tôi cần test lại bước nào.
```
