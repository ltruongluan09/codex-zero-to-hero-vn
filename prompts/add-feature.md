# Prompt thêm tính năng

```text
Tôi muốn thêm tính năng mới vào project hiện tại.

Tính năng:
[mô tả tính năng]

Người dùng cần tính năng này vì:
[lý do công việc]

Luồng sử dụng mong muốn:
1. Người dùng [bước 1].
2. App [bước 2].
3. Kết quả là [bước 3].

Yêu cầu:
- Giữ giao diện nhất quán với project hiện tại.
- Không làm hỏng tính năng đang có.
- Nếu có nhiều cách làm, hãy chọn cách đơn giản nhất cho bản đầu.

Sau khi làm xong, hãy cập nhật README nếu cần.
```
