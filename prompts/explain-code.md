# Prompt giải thích code

```text
Hãy giải thích phần code này cho người chưa từng lập trình.

Yêu cầu cách giải thích:
- Không dùng thuật ngữ khó nếu chưa giải thích.
- Dùng ví dụ đời thường.
- Nói rõ file này có vai trò gì trong project.
- Nói người mới có thể chỉnh phần nào an toàn.
- Nói phần nào không nên sửa nếu chưa hiểu.

Code hoặc file cần giải thích:
[dán code hoặc tên file]
```
