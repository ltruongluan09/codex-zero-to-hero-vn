# Prompt tạo project mới

```text
Tôi là [vai trò] và chưa biết code chuyên sâu.

Tôi muốn tạo một project tên là [tên project].

Mục tiêu project:
[mô tả project giúp giải quyết việc gì]

Người dùng chính:
[ai sẽ dùng]

Tính năng bản đầu tiên:
1. [tính năng 1]
2. [tính năng 2]
3. [tính năng 3]

Yêu cầu giao diện:
- Dễ dùng cho người không rành kỹ thuật.
- Nhìn hiện đại, rõ ràng, chuyên nghiệp.
- Dùng tốt trên laptop và điện thoại.

Hãy:
1. Đề xuất cấu trúc project.
2. Tạo bản đầu tiên chạy được.
3. Viết README hướng dẫn chạy.
4. Chạy thử và báo tôi mở link nào.
5. Giải thích ngắn gọn các file quan trọng.
```
