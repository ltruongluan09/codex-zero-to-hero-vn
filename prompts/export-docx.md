# Prompt export DOCX

```text
Tôi muốn xuất tài liệu Markdown trong project này thành DOCX chuyên nghiệp.

Hãy:
1. Kiểm tra các chapter cần xuất.
2. Đề xuất thứ tự nội dung.
3. Tạo một file Markdown tổng hợp nếu cần.
4. Áp dụng style theo templates/docx-style-guide.md.
5. Hướng dẫn tôi cách export sang DOCX bằng công cụ phù hợp.

Đối tượng đọc là người Việt không chuyên kỹ thuật, nên hãy ưu tiên tài liệu dễ đọc, nhiều heading rõ, prompt đặt trong box riêng, và có checklist cuối chương.
```
