# 10. Project là gì?

## Mục tiêu bài học

Hiểu project như một thư mục có tổ chức chứa toàn bộ sản phẩm.

## Vì sao phần này quan trọng?

Biết vai trò folder giúp bạn không bị lạc khi Codex nói "tôi đã sửa file này".

## Giải thích cực dễ hiểu

Project giống một bộ hồ sơ. Có bìa giới thiệu, tài liệu hướng dẫn, dữ liệu, hình ảnh, mã nguồn và cấu hình.

## Ví dụ thực tế ở Việt Nam

Một landing page có file nội dung, file giao diện, ảnh logo và README hướng dẫn chạy.

## Làm việc với Codex

Yêu cầu Codex giải thích cây thư mục.

## Prompt mẫu

```text
Hãy giải thích cấu trúc project này cho người không biết code. File nào quan trọng, file nào không nên sửa tùy tiện?
```

## Codex sẽ tạo ra gì?

Bản giải thích từng folder và file chính.

## Cách kiểm tra kết quả

Bạn chỉ ra được file README, thư mục source và nơi chứa assets.

## Lỗi thường gặp

- Sửa nhầm file cấu hình.
- Xóa file vì tưởng không quan trọng.

## Bài tập thực hành

Mở một project và viết lại vai trò của 5 file hoặc folder.

## Checklist cuối bài

- [ ] Tôi hiểu project là một thư mục.
- [ ] Tôi biết README dùng để làm gì.
- [ ] Tôi biết hỏi Codex trước khi sửa file lạ.
