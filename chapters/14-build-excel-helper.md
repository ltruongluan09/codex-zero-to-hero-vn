# 14. Build Excel helper

## Mục tiêu bài học

Tạo tool hỗ trợ xử lý dữ liệu bảng.

## Vì sao phần này quan trọng?

Rất nhiều công việc văn phòng đang bị lặp lại trong Excel. Đây là nơi AI có thể giúp tiết kiệm thời gian rõ nhất.

## Giải thích cực dễ hiểu

Excel helper giống một trợ lý nhận file, lọc dữ liệu, tính tổng và trả lại bảng gọn hơn.

## Ví dụ thực tế ở Việt Nam

Tool tổng hợp chấm công theo phòng ban từ file CSV.

## Làm việc với Codex

Mô tả tên cột và kết quả cần xuất.

## Prompt mẫu

```text
Tạo tool upload CSV chấm công với các cột: tên nhân viên, phòng ban, số ngày công, số ngày nghỉ. Tool cần hiển thị bảng, tổng hợp theo phòng ban và cảnh báo người nghỉ quá 3 ngày.
```

## Codex sẽ tạo ra gì?

Giao diện upload, bảng dữ liệu và phần tổng hợp.

## Cách kiểm tra kết quả

Dùng file mẫu nhỏ 5 đến 10 dòng để kiểm tra trước.

## Lỗi thường gặp

- Tên cột trong file khác với prompt.
- File có dữ liệu trống hoặc sai định dạng.

## Bài tập thực hành

Tạo dữ liệu CSV mẫu và nhờ Codex build helper.

## Checklist cuối bài

- [ ] Tôi biết mô tả cột dữ liệu.
- [ ] Tôi biết kiểm tra bằng file nhỏ.
- [ ] Tôi biết yêu cầu xuất kết quả.
