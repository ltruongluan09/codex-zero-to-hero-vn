# 11. Chạy project đầu tiên

## Mục tiêu bài học

Biết chạy một project web đơn giản trên máy.

## Vì sao phần này quan trọng?

Khi thấy app chạy trên browser, bạn sẽ hiểu AI không chỉ viết chữ mà có thể tạo sản phẩm thật.

## Giải thích cực dễ hiểu

Chạy project giống bật một cửa hàng demo trên máy bạn. Browser là nơi bạn ghé vào xem.

## Ví dụ thực tế ở Việt Nam

Bạn chạy landing page tuyển dụng và gửi screenshot cho trưởng phòng xem.

## Làm việc với Codex

Nhờ Codex chạy project và báo link mở thử.

## Prompt mẫu

```text
Hãy chạy project này giúp tôi. Nếu thiếu dependency thì cài theo cách phù hợp. Sau khi chạy được, hãy nói tôi mở link nào để xem.
```

## Codex sẽ tạo ra gì?

Lệnh chạy project, link local và hướng dẫn kiểm tra.

## Cách kiểm tra kết quả

Mở link local, refresh trang, thử bấm các nút chính.

## Lỗi thường gặp

- Đóng terminal làm app tắt.
- Chạy lệnh ở sai thư mục.

## Bài tập thực hành

Chạy một project mẫu và ghi lại link local.

## Checklist cuối bài

- [ ] Tôi biết app local là gì.
- [ ] Tôi biết terminal cần mở khi app chạy.
- [ ] Tôi biết kiểm tra app trên browser.
