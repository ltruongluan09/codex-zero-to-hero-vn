# 18. OpenAI API là gì?

## Mục tiêu bài học

Hiểu API là cách app nói chuyện với AI.

## Vì sao phần này quan trọng?

Muốn tạo chatbot hoặc tool AI thật, bạn cần hiểu app gửi yêu cầu tới AI và nhận câu trả lời về.

## Giải thích cực dễ hiểu

API giống quầy gọi món. App gửi "đơn gọi món" là câu hỏi hoặc dữ liệu, AI trả lại "món" là câu trả lời.

## Ví dụ thực tế ở Việt Nam

Tool báo cáo tuần gửi gạch đầu dòng lên AI, AI trả về bản nháp báo cáo.

## Làm việc với Codex

Yêu cầu giải thích API key, biến môi trường và chi phí bằng ví dụ đơn giản.

## Prompt mẫu

```text
Giải thích OpenAI API, API key và biến môi trường cho tôi như người chưa biết code. Dùng ví dụ app chatbot nội bộ.
```

## Codex sẽ tạo ra gì?

Giải thích dễ hiểu và các lưu ý bảo mật.

## Cách kiểm tra kết quả

Bạn phân biệt được app, API, API key và câu trả lời AI.

## Lỗi thường gặp

- Dán API key công khai.
- Không hiểu mỗi lần gọi API có thể phát sinh chi phí.

## Bài tập thực hành

Vẽ sơ đồ đơn giản: người dùng, app, OpenAI API, câu trả lời.

## Checklist cuối bài

- [ ] Tôi hiểu API là gì.
- [ ] Tôi hiểu API key là chìa khóa.
- [ ] Tôi biết không chia sẻ API key công khai.
