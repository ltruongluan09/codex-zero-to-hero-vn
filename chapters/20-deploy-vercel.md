# 20. Deploy Vercel

## Mục tiêu bài học

Biết đưa app web lên mạng bằng Vercel.

## Vì sao phần này quan trọng?

App chạy trên máy bạn thì chỉ bạn xem được. Deploy giúp người khác mở link và dùng thử.

## Giải thích cực dễ hiểu

Deploy giống mở cửa hàng online. Trước đó cửa hàng chỉ nằm trong máy bạn, sau deploy người khác có thể ghé qua bằng link.

## Ví dụ thực tế ở Việt Nam

Bạn deploy landing page khóa học rồi gửi link cho khách hàng tiềm năng.

## Làm việc với Codex

Nhờ Codex kiểm tra project đã sẵn sàng deploy chưa.

## Prompt mẫu

```text
Hãy kiểm tra project này đã sẵn sàng deploy lên Vercel chưa. Nếu cần biến môi trường, hãy hướng dẫn tôi cấu hình từng bước.
```

## Codex sẽ tạo ra gì?

Checklist deploy và hướng dẫn xử lý lỗi thường gặp.

## Cách kiểm tra kết quả

Mở link Vercel, thử chức năng chính, kiểm tra mobile.

## Lỗi thường gặp

- Quên biến môi trường.
- Build lỗi trên Vercel dù local chạy được.

## Bài tập thực hành

Deploy landing page đầu tiên và gửi link cho một người xem thử.

## Checklist cuối bài

- [ ] App có link public.
- [ ] Chức năng chính chạy trên link public.
- [ ] Không lộ API key.
