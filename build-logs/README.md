# Build Logs

Đây là nơi lưu nhật ký làm các project thật của Lumi Labs.

Mục tiêu của build log:
- ghi lại quá trình làm thật, không chỉ kết quả đẹp cuối cùng
- giải thích bằng ngôn ngữ dễ hiểu cho người không biết code
- cho thấy AI có thể giúp biến ý tưởng thành công cụ dùng được
- lưu lại bài học, lỗi gặp phải, quyết định sản phẩm và hướng cải thiện

Mỗi project nên có một file riêng.

Format đề xuất:

1. Bối cảnh
2. Ý tưởng ban đầu
3. Người dùng mục tiêu
4. Phiên bản đầu tiên
5. Những lần chỉnh quan trọng
6. Lỗi hoặc điểm chưa ổn
7. Bài học rút ra
8. Việc cần làm tiếp theo
